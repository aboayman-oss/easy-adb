The first public release of **Easy ADB**: everyday Android power tools for Windows with zero setup.

## Download

| File | What it is |
|---|---|
| `Easy-ADB-Setup-1.0.0.exe` | Installer for your Windows account (no admin rights needed). Recommended. |
| `Easy-ADB-Portable-1.0.0.zip` | Portable version. Unzip anywhere (a USB stick works) and run `Easy ADB.exe`. Its settings and tools stay inside that folder. |

On first launch Easy ADB downloads Google's official platform-tools and scrcpy (about 40 MB) and checks them. The app isn't code-signed yet, so Windows SmartScreen may ask you to confirm: **More info → Run anyway**.

## What's inside

- **Connect** over USB with brand-specific setup guides, or over Wi-Fi with QR code, pairing code or "Go wireless". Remembered phones reconnect by themselves.
- **Files**: a visual explorer with drag-and-drop, progress and speed, Unicode file names, and cleanup of half-copied files.
- **Apps & Debloat**: real names and icons, safety ratings, Turn off / Remove / Restore.
- **Install** `.apk`, `.xapk`, `.apks` and `.apkm` bundles, with plain-language errors.
- **Mirror** your screen (scrcpy) with quality presets and phone audio; take **screenshots** and **record** up to 3 minutes.
- **Device health**, **tweaks** (animation speed, display size with auto-revert, stay awake) and a safe **power menu**.
- An **Activity Log** that explains what happened in plain words.

## Known limitations

- Windows only (10 and 11, 64-bit).
- Tested most thoroughly on a Samsung Galaxy S24 Ultra with Android 17. Reports from other phones are very welcome.
- Not code-signed, so SmartScreen shows a warning the first time.
